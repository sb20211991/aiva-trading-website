HOW TO ADD / EDIT / PRICE / REMOVE PRODUCTS LATER
Edit data/aiva-products.json then redeploy Pages:
1. Add a product object under "products" with sku, name, description, category,
   pricePence (integer pence, e.g. 1250 = £12.50), stock, available true/false
2. Edit price by changing pricePence; set available=false to hide without deleting
3. Remove a product by deleting its object from the products array
4. Keep shopEnabled=false until you are ready for customers (or leave true only
   while sandbox-testing with Square sandbox credentials)
5. Update deliveryPolicy / returnsPolicy / businessAddress before go-live
6. Run: npm test && deploy (Cloudflare safe redeploy / Pages deploy)

SELLER SETUP (REMAINING)
1. Add GitHub Actions secrets (or Cloudflare Production secrets) for:
   SQUARE_ACCESS_TOKEN, SQUARE_LOCATION_ID, SQUARE_WEBHOOK_SIGNATURE_KEY
2. Confirm Square webhook → https://app.aivatrading.uk/api/square-webhook
   (events: payment.updated, order.updated)
3. Sandbox-test the £1 SKU, then ask before any production/live Square switch
4. Replace temporary test SKU with real products; set shopEnabled as you choose
